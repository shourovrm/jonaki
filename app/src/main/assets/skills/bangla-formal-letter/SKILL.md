# Bangla formal letter

The letter uses প্রমিত চলিত বাংলা (standard colloquial Bangla) throughout. Never mix সাধু forms (করিয়া, যাইতেছি) with চলিত forms (করে, যাচ্ছি) in one letter.

## Information to collect

Ask in one message for whatever is missing, and fill nothing in by guessing:

- Who receives it: post title and office (for example প্রধান শিক্ষক, ঢাকা রেসিডেনসিয়াল মডেল কলেজ).
- The purpose and the key facts: dates, amounts, reference numbers, reasons.
- The sender: name, and as needed class and roll, designation, ID, address, mobile number.

## Layout

```
তারিখ: ২ অক্টোবর ২০২৬

বরাবর
প্রধান শিক্ষক
[প্রতিষ্ঠানের নাম]
[ঠিকানা]

বিষয়: [এক লাইনে উদ্দেশ্য, যেমন: তিন দিনের ছুটির জন্য আবেদন।]

জনাব,
বিনীত নিবেদন এই যে, [মূল বক্তব্য: কে, কী, কেন, কবে — ছোট দুই-তিনটি অনুচ্ছেদে।]

অতএব, মহোদয়ের নিকট আকুল আবেদন, [নির্দিষ্ট অনুরোধ] দিয়ে বাধিত করবেন।

বিনীত নিবেদক
[নাম]
[শ্রেণি/পদবি, রোল/আইডি]
[মোবাইল নম্বর]
```

## Rules

- Write dates and numbers in Bangla digits (০১২৩৪৫৬৭৮৯), with the month in Bangla: ২ অক্টোবর ২০২৬.
- Salutation: "জনাব," for a man or an office; "মহোদয়া," for a woman when the user says so; "মহোদয়," as the neutral form inside the body.
- Keep the subject to one line ending in "।".
- Body: polite and specific, no flattery and no emotional pleading beyond one sentence. State dates and numbers exactly as the user gave them.
- Letter types and their closing request:
  - ছুটির আবেদন: the dates and the reason, then "...দিন ছুটি মঞ্জুর করে বাধিত করবেন।"
  - চাকরির আবেদন: the post, the advertisement reference, qualifications as a short list, then "...আমাকে উক্ত পদে নিয়োগ দানে আপনার মর্জি হয়।" and a list of enclosures (সংযুক্তি).
  - অভিযোগ / দাপ্তরিক চিঠি to an authority: the problem with place and date, the effect, then the specific action requested.
- Show the finished letter in the chat inside a code block, so the layout keeps its line breaks. If the user wants a file, save `artifacts/<subject>-letter.md`, or an HTML file with `lang="bn"`, A4 print margins of 2.5 cm and the font stack `"Noto Sans Bengali", sans-serif`.
