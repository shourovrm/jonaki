Jonaki — two design directions

Each direction shows the same three screens with the same content: the thread list, a thread with the agent running a search and asking for approval, and the search settings. Content is sample data. The switch changes every phone between the light and dark themes; the app itself follows the system theme and offers a manual toggle.

A · Rail line

Idea
An agent run is a journey on a railway timetable. Each tool step is a station on one track: filled when done, amber when the train is there, red when it waits for you.
Look
Cool green-grey ground, Bangladesh Railway green, signal amber for live work and signal red for Stop and Deny. Condensed capital labels and monospaced times, like a departures board.
Strength
Long research runs stay readable: you see where the agent is, how long each step took and what comes next.
Risk
It's denser and more technical than a typical chat app, so quick one-line asks feel more formal.

B · Firefly

Idea
The name made literal but quiet: everything at rest is dim, and only the thing that is working gives off light. A working thread's dot glows in the list; inside a run, only the running step glows.
Look
Leaf-dark ground at night and pale paddy green by day, one firefly yellow-green for live work, soft rounded Material You shapes, approval as a filled card.
Strength
Calm and friendly for quick asks and night use; you can tell at a glance which threads are working.
Risk
It's closer to a familiar dark chat app, and the step list shows less detail (no per-step times).
