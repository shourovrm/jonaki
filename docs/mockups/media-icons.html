Media buttons as icons on the status line

Two ways to move Picture, Vector and Video up beside the model, context, cost, web search and approvals controls, so that their own row disappears. Both keep option B: a tap on the details line opens one settings sheet.

The frames are the real widths: 411 dp is the test phone (A059), 360 dp is the narrow phone that AGENTS.md requires every screen to be checked on. The browser lays the rows out, so what is cut here is what would be cut on a phone of that width.

Variant 1: three icons on the status line

It does not fit. Even on the 411 dp test phone, with the context chip cut to "1%", the model's name disappears and only its dot is left; on a 360 dp phone the approvals button is pushed off the edge. Each icon is also 34 dp wide with no gap, which is under Android's 48 dp touch target.

Variant 2: one media button on the status line Recommended

One button opens a menu of the three kinds. Every control stays on the screen at each width, the button keeps room for a full touch target, and the menu shows each kind's model and price before the choice. It costs one more tap to switch a kind on, and on a 360 dp phone the model's name shrinks to its dot once the cost chip is as wide as "$0.0070".
