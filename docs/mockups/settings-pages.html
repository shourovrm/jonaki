Grouping. Models covers chat services and subagent models. Web and YouTube covers search order and the Gemini key. Tools and approvals covers tool switches, Python, MCP servers and the default approval mode. Answers covers style, custom instructions and personas. Memory and skills covers both libraries. Files and schedule covers the linked folder, reminders and scheduled tasks. Theme, Permissions and About each get their own page.

Second lines are live. Each row's second line shows the state you would otherwise open the page to see: balance, search order, how many tools are on, the default approval mode, the answer style, counts of facts and skills. Permissions turns red only when something is denied, so a problem shows on the first page.

Search settings. One field at the top finds a setting by name ("Python", "persona", "Tavily") and opens its page. It is optional; the first page fits on one screen without it.

No cards, no labels over groups. Three groups are separated only by space. Sub-pages use plain section labels and thin lines between rows, like the rest of the revamp. Back returns to the first page at the same place.

Links from elsewhere. The chat's "Add one in Settings" errors and the permission rows open the right sub-page directly, not the first page.
