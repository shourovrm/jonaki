Jonaki — OpenRouter routing

OpenRouter serves most models through several providers. Three choices decide which provider answers. Private, then cheapest uses only providers that don't store or train on your data, and among those the cheapest. Cheapest uses the cheapest provider. Automatic leaves it to OpenRouter. The OpenRouter card sets the choice for all its models, and each model can override it. Three layouts for that.

A · Card setting, override in the model's menu

Card
A three-way switch under the key sets routing for every OpenRouter model.
Model
The model's ⋮ menu has the same three choices plus "Same as OpenRouter". A model that differs shows a small label under its prices.
Strength
Most people set it once; the card stays calm.
Risk
Overrides are hidden in a menu.

B · Routing chip on every model

Model
Each OpenRouter model row has a small chip under its prices showing its routing as an icon and word. Tap the chip to change it. New models take the card's choice.
Strength
You see every model's routing at a glance and change it in one tap.
Risk
Busier rows; each model takes one more line.

C · Model sheet

Model
Tapping a model row opens a sheet with everything about that model: default star, the three routing choices with one line each, prices and context, and Remove. The card has no routing control; the sheet's "Use for all OpenRouter models" sets it everywhere.
Strength
Each choice is explained where you make it; room for more per-model options later.
Risk
Setting all models at once is one step deeper.

Threads · full names and Rename

List
Thread names wrap so the whole name shows; the preview line under it stays one line.
Rename
Long-press a thread for Rename and Delete. Inside a thread, Rename is also in the ⋮ menu. The dialog starts with the current name selected.
Note
New threads still take their name from the first message; Rename replaces it.
