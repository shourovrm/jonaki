Direction A: four colour themes, dark and light

Layout, type and shapes are the same as A. Only the colours change. In each theme the colour of live work (glow dot, running step) is fixed. Buttons use either the same hue or plain ink, so no theme has a second accent. Each row shows dark mode on the left and light mode on the right.

1. Leaf

Today's leaf-dark and paddy-green colours, tuned for contrast. This is the safe choice: the app looks like itself, only calmer.

2. Monsoon

A blue-slate night sky with the firefly against it. The firefly yellow-green stands out more here than on green. In light mode buttons are ink-black, so the only colour on screen is live work.

3. Lantern amber

The firefly as warm lamplight on neutral charcoal and grey-white. This moves away from green entirely. It suits evening reading, but changes the brand colour of D-024 and the logo.

4. Graphite

Neutral greys with no tint and one bright green. It is the most "tool-like" and the closest to the apps people already use. The brand lives only in the green.
