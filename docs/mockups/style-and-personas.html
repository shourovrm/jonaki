Jonaki — custom instructions, answer style and personas

Settings holds the general instructions, the default answer style and the saved personas. In a thread, the ⋮ menu opens one sheet for that thread's answer style, persona and own instructions. The model reads them in this order, and the later part wins: answer style, general instructions, persona, this thread's instructions. Decisions D-STY-1 to D-STY-3.

Settings

Answers
Answer style for every thread that has not picked its own. "Custom instructions" opens an editor; its first line shows under the row, or "None".
Personas
One row per persona, the name on one line with "…". Tapping opens the editor; "Add persona" opens an empty one.
Editor
Name (personas only) and instructions, at most 8,000 characters each text; the counter shows the length. Save in the app bar. Delete asks first; threads that used the persona go back to none.

In a thread

Menu
One new item, "Style and persona", shown in every thread, also before the first message.
Sheet
Answer style with Default (follow Settings), persona with None, and this thread's instructions with Save. Style and persona apply on tap; all three reach the next message.
Cache
Each change rewrites the system prompt once, so the next request misses the provider's prompt cache once; requests after it hit the cache again (D-005).
No personas
The persona part shows "No personas. Add one in Settings."
