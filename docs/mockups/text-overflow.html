Jonaki — long text and model prices

The same screens with long names. Every model shows three prices per million tokens: input, output and cached input. The rule for long text: the name keeps one line and ends in "…"; the id and the numbers get lines of their own, so no number is ever cut off. In the status strip the model name shrinks first, so context, use and cost stay whole.

Model lists

Row
Line 1: name, with the context window at the right. Line 2: the model id, shortened with "…" if needed. Line 3: in, out and cache prices in fixed columns, so rows line up.
Was
Id, context and prices shared one line, and the prices ran off the screen ("$0.07 /").

Chat screen

Strip
The model pill takes the space that is left and ends in "…"; context, use and cost keep their full width. Tapping the pill shows the full name in the menu.
Title
One line with "…"; the full title is in the overflow menu's Rename.
Steps
Long links and paths in steps and approval cards wrap onto a second line instead of running off; a third line ends in "…".
