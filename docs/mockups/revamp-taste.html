Jonaki revamp: three directions

The same two screens (thread list and a chat with a running agent) in three looks. A keeps today's night theme and removes clutter. B makes the day theme the main look. C is denser and puts numbers first. All three keep Material 3 structure, the lit j, the glow dot for live work and the step track from D-024. The planned changes are already in: title-only top bar, a globe pill for web search, and the "+" button in the composer.

A. Lantern

The leaf-dark night theme stays. The yellow-green appears only where something is live: the glow dot, the running station and the send button. Agent answers have no bubble, so long text reads like a page.
