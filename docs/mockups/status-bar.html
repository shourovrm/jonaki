Status line alternatives

Six ways to keep the model's name readable beside the context, cost, media, web search and approvals controls. Each is drawn on the test phone's width (411 dp) with Claude Haiku 5.5 and on a 360 dp phone with a longer name, DeepSeek V4.1 Flash, and a cost as wide as the strip has to hold.

The browser lays every row out from the app's own sizes, so a name that is cut here would be cut on a phone of that width. Each icon button keeps the 48 dp of row it takes in the app today, unless the caption says otherwise.

Today (1.4.3)

Three icon buttons take 48 dp each for touch, so the name is the part that gives way.

1. Short name with a maker badge

The maker's word leaves the name ("Anthropic: Claude Haiku 5.5" becomes "Claude Haiku 5.5") and a round badge with the maker's initial stands for it. Cost: nothing moves; the badge replaces the green dot, so the "agent is working" glow needs another home (the badge itself can glow).

2. One capsule for the three toggles

Media, web search and approvals share one capsule with 40 dp cells, which frees about 36 dp for the name. Cost: each cell is 8 dp under Android's 48 dp touch width, and a selected state has to be drawn inside a shared shape.

3. Context and cost in one meter

The ring and the cost share one pill; a tap opens one sheet with both. Cost: the percent number is gone from the strip (the ring still fills), and two sheets become one.

4. Model under the thread title Recommended

The name moves to the top bar as a second line under the title, where a whole line is free; a tap there opens the model sheet. The strip keeps only numbers and toggles. Cost: the model is no longer next to the message box, and the top bar grows by about 16 dp.

5. Model inside the message box

A small chip at the start of the message box names the model; the strip loses its model pill. Cost: the typing area is narrower by the chip's width, and the chip has to hide once text is typed or the box wraps.

6. Two lines

The model gets its own line with its service; the controls sit on the line below. Cost: 32 dp of chat height on every screen, which is the row the media button just saved.
