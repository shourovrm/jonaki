First run v2: three ways to start

Version 1 asked a newcomer for an API key on card 1, and a newcomer without a key could only press Skip. In this version card 1 offers a free service run by Jonaki, a small model that runs on the phone, or the user's own key. The rest of this page covers the key step, the model picker, the chat error, the empty model state and Settings, because each of them failed a person who had no key or the wrong plan. Every screen is shown in the dark and light theme.
