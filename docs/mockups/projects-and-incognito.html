Jonaki — projects and incognito chat

A project groups threads. The thread list gets a row of filter chips under the search field: All, one chip per project, and "Project" to make a new one. A thread joins a project from its long-press menu (Move to project), or by starting it while the project's chip is selected. An incognito chat is marked with a lock in the list and a banner in the chat; it uses no memory and is deleted a day after its last message unless the user keeps it.

Projects in the thread list

Chips
All, then each project by name (one line, "…"), then "+ Project". The row scrolls sideways. The chips show once there is a thread or a project.
All
A thread in a project shows the project name before its last line.
One project
A header with the project name (wraps), its model if set, and ⋮ with Edit project and Delete project. New thread starts in this project with its model.
Delete
Only the project goes; its threads stay, without a project.

Incognito chat

Start
The lock button in the thread list's bar opens a new incognito chat.
Banner
Stays above the messages while the thread is incognito. Keep turns it into a regular thread and the banner goes.
Memory
No memory tool, no facts in the prompt, no extraction. The ⋮ menu has no Memory item.
Deletion
One day after the last message, at the next app start or thread list view.
