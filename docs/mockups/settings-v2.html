Grouping

The home page follows the question a user arrives with. "Models and keys" answers "can Jonaki answer". "What Jonaki can do" lists the abilities. "Memory" is separate because facts and skills are things the user edits, not switches. "Safety" holds everything that decides whether an action runs. "Look and feel" holds Theme, the status strip and the answer style. Two changes to the proposal: the Memory group is titled "Memory" and holds two rows, "Saved facts" and "Skills", because a group "Memory and skills" over one row of the same name repeats itself; and "Files" and "Reminders and schedule" are separate rows because today's "Files and schedule" joins a folder link to a reminder list that have nothing in common.
